# data/

이 폴더의 데이터 파일은 커밋하지 않는다 (`.gitignore`로 `data/README.md`만 예외). KAMP 원본과 가공 데이터는 각자 내려받거나 생성한다.

## 폴더 구조

```
data/
  README.md      이 문서 (유일하게 커밋되는 파일)
  raw/           KAMP에서 내려받은 원본. 수정·삭제·덮어쓰기 금지
  processed/     전처리 파이프라인(src/pipeline/)이 만든 결과. 재생성 가능
```

- `data/raw`는 불변이다. 에이전트와 코드는 읽기만 한다.
- `data/processed`는 `data/raw`와 파이프라인 코드로 언제든 다시 만들 수 있어야 한다.
- 폴더 안의 세부 구조는 선택한 데이터셋에 따라 달라진다. 확정되면 `docs/data/data-dictionary.md`에 기록한다.

## KAMP 데이터 직접 받기

1. KAMP 인공지능 제조 플랫폼(https://www.kamp-ai.kr, 2026-10-11 접근)에 접속한다.
2. 데이터셋 목록에서 `docs/research/kamp-candidates.md`의 후보 중 사용자가 선택한 데이터셋을 찾는다.
3. 이용 조건을 읽고 동의한 뒤 내려받는다. 회원가입이나 활용 신청이 필요한지는 사이트에서 직접 확인한다 (이 문서에서는 미검증).
4. 압축을 풀어 `data/raw/<데이터셋 이름>/` 아래에 원본 파일 그대로 둔다.
5. 내려받은 날짜와 데이터셋 이름·버전을 `docs/data/`의 데이터 사전에 기록한다.

## 이용 약관과 재배포

- 원본 데이터를 이 레포, 이슈, PR, 노트북 출력, 문서에 올리거나 재배포하기 전에 KAMP의 이용 약관과 데이터셋별 이용 조건을 확인한다. 재배포 가능 여부는 이 레포에서 확인된 바 없다 (미검증).
- 노트북 출력과 문서에 원본 행 단위 데이터를 그대로 싣지 않는다. 집계 결과와 요약 통계만 쓴다.
- 이 레포의 MIT 라이선스는 코드와 문서에만 적용된다. 데이터는 KAMP의 조건을 따른다.
